# Tradex - Multi-Agent AI Investment Platform

## Overview

Tradex is a multi-agent AI-powered investment platform designed to provide personalized investment recommendations based on user risk profile, investment amount, and tenure.

The system combines market research, risk assessment, and portfolio management through independent AI agents working together to generate intelligent investment strategies.

---

## Features

### User Management
- User Registration & Login
- Profile Management
- Secure Authentication

### Investment Planning
- Risk-Based Investment Selection
- Investment Amount Analysis
- Tenure-Based Recommendations

### AI-Powered Recommendations
- Market Research Agent
- Risk Profiling Agent
- Portfolio Management Agent

### Portfolio Tracking
- Asset Allocation
- Performance Monitoring
- Profit/Loss Analysis
