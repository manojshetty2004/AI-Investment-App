# AI Investment App

## Project Overview

An AI-powered investment application that automatically invests based on a user's risk profile.

### Risk Levels

🟢 Low Risk
- Mutual Funds
- SIP

🟡 Medium Risk
- Stocks
- ETFs

🔴 High Risk
- Stocks
- Futures & Options
